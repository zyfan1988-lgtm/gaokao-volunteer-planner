# 服务说明、价格与退款规则

本文件为对外沟通的默认版本。具体报价、交付范围和排期以双方确认的订单或书面说明为准；如与适用法律或消费者权益保护规定冲突，以适用法律为准。

## 服务范围

| 服务 | 默认建议价 | 交付内容 |
| --- | ---: | --- |
| 初步筛选 | 299 元 | 条件复盘、候选方向、资料缺口与风险提示 |
| 标准志愿方案 | 699 元 | 冲稳保清单、专业/专业组风险、来源复核清单 |

以上为默认建议价，服务方可在公开前调整；调整后应同步更新本文件。特殊类型、跨省复杂方案、紧急服务、线下服务和数据治理项目应另行确认范围与报价。

## 不包含的内容

- 不承诺录取、调剂结果、就业薪资或升学结果。
- 不代填、代报、代缴费，不保管考生账号、密码、短信验证码或证件原件。
- 不提供、出售或上传受版权、登录、付费、授权限制的第三方或考试院数据。
- 不提供违法违规、规避平台限制或伪造材料的协助。

## 退款规则

- 服务开始前，若尚未进行数据检索、方案制作或咨询，可全额退款。
- 已完成信息收集和初步筛选，但未交付方案，可退已付费用的 50%。
- 已交付约定方案、来源复核清单或已完成约定咨询，不支持因录取结果、分数变化、个人偏好变化或未采纳建议而退款。
- 因服务方未按约定范围交付，先在合理期限内免费补正；无法补正的，按未交付部分比例退款。
- 因考生/家长隐瞒、误报或迟延提供关键信息，或因官方政策、计划、投档规则临时变化导致方案需调整，不视为服务方违约；可按已完成工作量协商补充服务。

## 隐私与沟通

- 仅收集完成服务必需的信息，优先使用脱敏截图与位次口径。
- 公开 GitHub Issue 不接收个人敏感信息。私密资料的保存期限、删除方式和用途应在服务前确认。
- 所有最终志愿由考生本人在官方系统复核和提交。
