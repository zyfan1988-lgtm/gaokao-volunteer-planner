# 方案交付与来源复核清单

用于交付前、正式填报前各核对一次。未完成的项目应明确标为“待确认”，不能以经验补齐。

## 一、考生条件

- [ ] 省份、年份、科类/选科、分数和位次口径已确认。
- [ ] 特殊类型资格、体检结论、外语语种、单科要求和政治面貌等限制已确认。
- [ ] 地域、院校层次、专业方向、预算、调剂与不能接受项已确认。
- [ ] 家长/考生已确认可接受的最差结果。

## 二、数据与来源

- [ ] 每个关键结论标有数据年份、批次、轮次、来源链接和检索日期。
- [ ] 当年省考试院政策、招生计划、一分一段和投档规则已核对。
- [ ] 目标高校招生章程、选科要求、学费、校区、专业说明和录取规则已核对。
- [ ] 首轮投档与第2/3次志愿、征集或补录数据未混用。
- [ ] 第三方数据仅用于交叉验证，并标注“非官方，需复核”。

## 三、方案内容

- [ ] 冲、稳、保均有可接受的学校、城市、专业和成本。
- [ ] 专业组内专业、调剂去向、大类分流和转专业风险已说明。
- [ ] 学生可理解每个关键取舍；家长已知悉成本、风险和不确定性。
- [ ] 对计划变化、数据缺口和预测边界已明确标注。

## 四、正式填报前

- [ ] 考生本人登录目标省官方系统，逐项核对院校/专业代码、志愿顺序和批次。
- [ ] 考生本人核对系统显示的专业名称、选科提示、收费标准和限制。
- [ ] 考生本人在截止时间前完成提交并保存官方回执或截图。
- [ ] 服务方未代填、未保管密码、未接收短信验证码。
