# 高考志愿填报决策 Skill

这是一个面向 Codex 的中国高考志愿填报工作流。它把学生的分数/位次、选科、地域、院校层次、专业方向、预算和禁忌项，转化为可复核的候选池、冲稳保排序与风险清单。

它解决的不是“凭印象推荐学校”，而是帮助使用者把以下事情做清楚：

- 用省内位次、批次和同口径历史数据建立候选池；
- 核验选科、专业组、体检、语种、单科、学费、校区和调剂风险；
- 解释学校、专业、城市、成本和就业出口之间的取舍；
- 区分首轮投档、征集/补录和不同录取规则下的数据；
- 在提交前形成一份由考生本人在官方系统复核的填报清单。

## 安装

将仓库克隆后，把 `gaokao-volunteer-planner` 目录放入 Codex 的 Skills 目录，例如：

```powershell
git clone https://github.com/zyfan1988-lgtm/gaokao-volunteer-planner.git
Copy-Item .\gaokao-volunteer-planner "$env:USERPROFILE\.codex\skills\gaokao-volunteer-planner" -Recurse
```

重启 Codex 或新建任务后，以自然语言提出志愿填报需求即可触发。需要使用查询脚本时，先安装依赖：

```powershell
pip install -r requirements.txt
```

本仓库不附带录取数据。请将你有权使用、已标准化的数据放在独立数据目录，并参照 [数据目录约定](references/data-layout.md) 调用：

```powershell
python scripts/query_local_data.py --data-root <数据目录> --actual-keyword 电气
```

## 使用示例

以下是虚构示例，不对应任何真实考生或录取结论。

**输入**

```text
省份：示例省
选科：物理、化学、生物
位次：约 8 万
地域：不限
院校层次：公办本科优先
专业方向：电气、自动化、计算机
不能接受：高学费中外合作、医学、护理、定向服务
家庭预算：学费每年不超过 1 万元
```

**输出摘要**

```text
结论：以“电气/自动化为主、计算机为补充”建池；将专业组内含医学或高学费项目的志愿列为高风险。

冲：近三年首轮最低位次在 6.8 万--7.7 万的相关专业，需复核当年计划是否缩减。
稳：近三年首轮最低位次在 7.7 万--8.8 万的公办本科相关专业。
保：近三年首轮最低位次在 9.2 万以后，且校区、学费、专业均可接受的项目。

待确认：目标省当年招生计划、选科要求、各院校招生章程、专业组内全部专业、体检限制和最终代码。
```

## 数据与责任边界

- 不上传、不分发受版权、登录、付费、授权限制或仅供个人使用的数据。
- 不上传第三方平台导出数据、考试院原始受限资料、客户案例、最终方案和学生个人资料。
- 仅使用有权使用的数据；公开仓库只提供流程、字段规范和本地查询工具。
- 不承诺录取结果，不替代省考试院、高校招生网或阳光高考的当年官方信息。
- 不代填志愿、不保管账号密码；志愿须由考生本人在官方系统完成提交。
