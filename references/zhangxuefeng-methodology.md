# 就业导向校验框架

本参考只提炼公开讨论中常见的“普通家庭就业导向”判断，不代表或模仿任何个人观点。

1. 先看普通毕业生的典型去向，不以极少数明星个例替代整体结果。
2. 专业优先时，核对课程、技能壁垒、资格要求、岗位入口、读研必要性和地域流向。
3. 学校优先时，核对目标专业的培养质量、校区、行业资源、转专业规则和专业组风险。
4. 地域优先时，核对城市产业、实习与校招机会、生活成本及为地域偏好付出的学校/专业代价。
5. 对金融、法学、传媒、商科等强平台路径，明确学校层次、城市平台和家庭资源的影响；对任何专业都不把“热门”直接等同于高就业。
6. 对医学、军警、公费、定向、航海、飞行、艺术体育等路径，先核验资格、学制、体检、服务协议和违约责任。

所有具体薪资、就业率、保研率、招生资格和录取概率，必须回到当年官方或学校材料验证。
